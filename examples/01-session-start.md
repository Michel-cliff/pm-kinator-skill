# Example 01: Session Start and Profile Setup

**Scenario:** First session. No profile file exists on disk. Solo founder, building a B2B SaaS, new to project management.

---

**User:** hey, let's get started

**Assistant:**
New session. Run `whoami` to set up your profile, or just paste your board state and we'll get going.

---

**User:** whoami

**Assistant:**
Before we start, a few things so I can work the way you do:

1. **Role:** What's your role? Are you solo or working with a team?
2. **Tools:** What tools do you use day-to-day? Name them or pick categories: email client, board or PM tool, messaging (Slack / Teams / other), calendar, code platform. Say "none" for anything you don't use.
3. **Rhythm:** Do you work in sprints, milestones, or a running backlog? How do you usually start your day?
4. **Pain point:** What's your biggest frustration with how work gets managed right now?
5. **Success:** What does a good week look like for you?
6. **Experience:** How comfortable are you with project management? (new to it / learning / experienced)

Short answers are fine.

---

**User:**
1. Solo founder, just me
2. Gmail, Linear, no calendar
3. Running backlog, I check emails first thing
4. I never know what to work on, everything feels urgent
5. Shipped something and cleared my inbox
6. New to it honestly

**Assistant:**

```
Your PM Profile

Role:       Solo founder, no team
Tools:      Gmail, Linear
Rhythm:     Backlog, starts with email
Pain point: Everything feels urgent, hard to know what to focus on
Success:    Ship something and clear the inbox

How I'll adapt:
- No delegation framing. Every ticket is yours.
- Lead each session with a ranked focus list, not a dump of everything open.
- Learning mode on. Concepts explained as they come up, anti-patterns flagged not silently fixed.
```

Profile saved. I'll remember this next time.

Paste your current backlog or board state and we'll get to work.
